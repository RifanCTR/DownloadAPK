# Panduan Penggunaan Aplikasi Kalkulator
Berikut penjelasan mengenai fitur-fitur yang tersedia dan cara menggunakan aplikasi kalkulator ini.

1. Saat Pertama Kali Membuka Aplikasi
    Saat pertama kali masuk ke aplikasi, kamu akan diminta melakukan beberapa pengaturan awal.

# Akses Kamera
  Kamu akan diminta memberikan izin akses kamera.
  Tenang, akses kamera ini memiliki fungsi khusus dan akan digunakan untuk fitur keamanan **Lupa Kata Sandi**. Penjelasan lengkap mengenai 
  fitur tersebut akan dijelaskan di bagian berikutnya.

  Untuk melanjutkan, pilih **"Izinkan saat aplikasi digunakan"**.

# Tanggal, Bulan, dan Tahun
  Selanjutnya, kamu akan diminta memasukkan **tanggal, bulan, dan tahun**.
  Kamu bebas menentukan tanggal yang ingin digunakan, tetapi **pastikan kamu mengingatnya**, karena data ini 
  akan digunakan sebagai bagian dari proses keamanan dan pemulihan akses.

# Membuat PIN Private Gallery
  Setelah itu, kamu akan diminta membuat **PIN untuk Private Gallery**.
  Pastikan PIN ini kamu ingat karena akan digunakan ketika ingin masuk ke **Private Gallery** melalui aplikasi kalkulator.
  Setelah PIN berhasil dibuat, kamu akan langsung diarahkan ke halaman **Private Gallery**.

# 2. Cara Masuk ke Private Gallery
  Setelah selesai melakukan pengaturan awal, kamu bisa memilih **"Kembali ke Kalkulator"**.
  Kamu juga bisa keluar dari aplikasi dan membukanya kembali.
  Saat berada di halaman kalkulator, tidak akan terlihat adanya fitur atau menu khusus untuk membuka Private Gallery.
  Untuk masuk ke Private Gallery, masukkan kode:
  **404=**

  Setelah itu, kamu akan diarahkan ke halaman **PIN Private Gallery**.
  Masukkan PIN yang sudah kamu buat pada pengaturan awal untuk membuka Private Gallery.

# 3. Fitur "Lupa Kata Sandi"
  Jika kamu lupa PIN Private Gallery, tersedia tombol **"Lupa Kata Sandi"**.
  Di sinilah fungsi izin kamera yang diminta saat pertama kali menggunakan aplikasi.
  Jika seseorang mencoba membuka Private Gallery menggunakan PIN kalkulator dan kemudian memilih **"Lupa Kata Sandi"**, aplikasi 
  akan menggunakan **kamera depan untuk mengambil foto secara otomatis**.
  Foto tersebut kemudian akan disimpan di **Private Gallery** sebagai bagian dari fitur keamanan.
  Foto keamanan tersebut juga memiliki perlindungan tambahan. Foto tidak dapat dengan mudah dipindahkan atau dipulihkan ke 
  galeri biasa tanpa melalui proses keamanan yang telah ditentukan.

# Perlindungan Foto Keamanan
  Foto yang diambil melalui tombol **"Lupa Kata Sandi"** memiliki perlindungan khusus.
  Untuk memulihkan foto tersebut ke galeri biasa, diperlukan **PIN serta tanggal, bulan, dan tahun** yang telah dibuat saat pertama kali melakukan pengaturan aplikasi.
  Sementara itu, **foto, video, dan file biasa** yang kamu masukkan ke Private Gallery dapat dipulihkan ke galeri biasa tanpa perlu memasukkan data tersebut.
  Jadi, secara singkat:

> **Hanya foto yang diambil melalui fitur "Lupa Kata Sandi" yang mendapatkan perlindungan tambahan.**
  Fitur ini dibuat agar kamu dapat mengetahui jika ada seseorang yang mencoba mengakses Private Gallery melalui aplikasi kalkulator.

# 4. Fitur di Private Gallery
  Di dalam **Private Gallery**, terdapat tiga jenis file yang dapat disimpan:

* Foto
* Video
* File

  Kamu dapat memasukkan file-file tersebut ke dalam Private Gallery sesuai kebutuhan.
  Untuk mengembalikan foto atau video ke galeri biasa:

1. Pilih **foto atau video** yang ingin dikembalikan.
2. Tekan **"Kembalikan ke Galeri"**.
3. File akan dikembalikan ke galeri biasa.

# 5. Pengaturan Private Gallery
  Di bagian kanan atas Private Gallery terdapat menu **Pengaturan**.
  Di dalam menu tersebut terdapat beberapa fitur:

# Bahasa

Tersedia dua pilihan bahasa:
* **Bahasa Indonesia**
* **English**

Kamu dapat mengganti bahasa aplikasi sesuai kebutuhan.
### Atur PIN Private Gallery
Fitur ini digunakan untuk mengganti PIN yang digunakan untuk masuk ke Private Gallery.
Kode awal untuk masuk melalui kalkulator adalah:

**404=**

Kamu dapat mengganti PIN tersebut dengan kombinasi angka sesuai keinginan.
Setelah memasukkan PIN baru, tanda **"="** berfungsi sebagai tombol konfirmasi.

# Privacy High
**Privacy High** merupakan fitur yang mengatur apakah kamera digunakan oleh fitur **"Lupa Kata Sandi"**.
  Jika **Privacy High = ON**:

* Kamera akan aktif ketika seseorang menggunakan fitur **"Lupa Kata Sandi"**.
* Foto akan diambil menggunakan kamera depan.
* Foto tersebut akan disimpan di Private Gallery.

Jika **Privacy High = OFF**:

* Aplikasi tidak akan mengambil foto ketika seseorang menggunakan fitur **"Lupa Kata Sandi"**.
* Kamera tidak akan digunakan untuk fitur tersebut.

## Ringkasan Alur
**Pertama kali menggunakan aplikasi:**
Kamera → Tanggal/Bulan/Tahun → Buat PIN → Private Gallery
**Untuk masuk kembali:**
Kalkulator → Masukkan **404=** → Masukkan PIN → Private Gallery
**Jika lupa PIN:**

Private Gallery → **Lupa Kata Sandi** → Proses pemulihan keamanan

**Pengaturan:**
Private Gallery → Pengaturan → Bahasa / Atur PIN / Privacy High
